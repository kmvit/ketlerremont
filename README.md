# КетлерСпорт — сайт сервиса спортивного оборудования на КМВ

Статический сайт по ремонту и обслуживанию спортивных тренажёров в Пятигорске,
Ессентуках, Кисловодске, Железноводске и Минеральных Водах.

Без фреймворков и зависимостей: чистые HTML/CSS/JS + маленький сборщик на Python,
который собирает страницы из `config.json` и шаблонов. Заливается на любой хостинг
простым копированием файлов.

---

## Быстрый старт

```bash
python3 build.py
```

Команда пересобирает все страницы. Локальный просмотр:

```bash
python3 -m http.server 8765
```

Затем откройте <http://localhost:8765>.

## Что нужно заполнить перед публикацией

Всё в одном файле — **`config.json`**, блок `brand`:

| Поле | Что это |
|---|---|
| `name`, `legal_name`, `inn` | Название бренда и реквизиты для подвала |
| `phone_display` / `phone_raw` | Основной телефон: как показывать / как в `tel:` |
| `phone2_display` / `phone2_raw` | Второй телефон (городской) |
| `email` | Почта для заявок |
| `whatsapp` | Номер для `wa.me/…`, только цифры: `79380000000` |
| `telegram` | Логин без `@` |
| `address`, `work_hours`, `work_hours_iso` | Адрес и график (ISO — для микроразметки) |
| `site_url` | Домен без слэша на конце — идёт в canonical, sitemap, JSON-LD |
| `geo.lat` / `geo.lon` | Координаты мастерской для микроразметки |
| `form_endpoint` | Куда отправлять заявки (см. ниже). Пусто — форма честно скажет, что отправка недоступна |
| `metrika_id` | Номер счётчика Яндекс.Метрики. Пусто — счётчик не подключается |

После правок — снова `python3 build.py`. Сборщик в конце печатает список того,
что ещё осталось заполнить.

### Обязательно замените

- **Отзывы** — в `config.json` → `reviews` сейчас лежат заглушки («Имя Фамилия»,
  «Заменить текст на реальный отзыв»). Публиковать выдуманные отзывы нельзя:
  это и вводит клиентов в заблуждение, и нарушает закон о рекламе.
  Замените на настоящие, затем поставьте `"reviews_are_placeholders": false`.
- **Политику конфиденциальности** — `templates/privacy.html` содержит типовой
  шаблон. Проверьте его с юристом: состав данных, сроки хранения, реквизиты.
- **Цены** — в `config.json` → `price_groups` указаны ориентировочные значения
  по рынку. Приведите к своим.
- **Карту** — в `templates/index.html` найдите блок `.map-embed` и вставьте
  `<iframe>` из конструктора Яндекс.Карт.

## Куда приходят заявки

Форма намеренно короткая — три поля: `name`, `phone`, `consent`. Всё остальное
мастер выясняет по телефону: чем меньше полей, тем выше конверсия.
Дополнительно уходит скрытое поле `source` — с какой страницы пришла заявка
(«Главная страница», «Ессентуки», «Кисловодск» и т. д.), чтобы понимать,
какой город даёт обращения.

Формы отправляют `FormData` методом POST на `brand.form_endpoint`. Варианты:

1. **Свой PHP-скрипт на хостинге** — `form_endpoint: "/send.php"`,
   скрипт шлёт письмо через `mail()` или SMTP.
2. **Готовый сервис** — Formspree, Getform, FormCarry: указываете их URL.
3. **Telegram-бот** — небольшой обработчик на сервере, который пересылает заявку в чат.

Если поле пустое, форма проходит валидацию, но вместо отправки показывает
сообщение с просьбой позвонить — заявка не теряется молча.

В форме есть скрытое поле-ловушка `company`: если бот его заполнит, заявка
не уйдёт на сервер.

## Структура

```
config.json                      ← все данные и контакты
build.py                         ← сборщик (только стандартная библиотека)
templates/
  base.html                      ← общий каркас: <head>, шапка, подвал
  index.html                     ← содержимое главной
  city.html                      ← шаблон страницы города
  privacy.html                   ← политика конфиденциальности
  icons.svg                      ← SVG-спрайт иконок
assets/
  css/style.css                  ← вся вёрстка, светлая и тёмная темы
  js/main.js                     ← меню, валидация, маска телефона, анимации
  img/favicon.svg
```

Сгенерированные файлы (их не редактируют вручную — перезапишутся):

```
index.html
remont-trenazherov-pyatigorsk.html
remont-trenazherov-essentuki.html
remont-trenazherov-kislovodsk.html
remont-trenazherov-zheleznovodsk.html
remont-trenazherov-mineralnye-vody.html
privacy.html
sitemap.xml
robots.txt
```

### Как добавить город

Добавьте объект в `config.json` → `cities` (`slug`, `name`, `in`, `gen`, `lead`,
`areas`, `local`) и пересоберите. Страница, ссылки в подвале, карточки в блоке
«География» и запись в `sitemap.xml` появятся сами.

### Как добавить услугу или строку прайса

`config.json` → `services` / `price_groups`. Иконка задаётся именем из
`templates/icons.svg` (например `wrench`, `gauge`, `package`).

## Публикация

`build.py` собирает страницы в корень проекта. Чтобы получить папку, готовую
к заливке, выполните:

```bash
python3 build.py && rm -rf dist && mkdir dist && cp *.html sitemap.xml robots.txt dist/ && cp -R assets dist/ && rm -f dist/assets/img/hero.png && (cd dist && zip -qr ../ketlersport-site.zip .)
```

Получатся папка `dist/` (1,3 МБ) и архив `ketlersport-site.zip` (0,9 МБ).

### Бесплатно, для теста

| Куда | Как | Нужен аккаунт |
|---|---|---|
| **Netlify Drop** — `app.netlify.com/drop` | Перетащить папку `dist` в окно браузера, ссылка выдаётся сразу | Нет для первого деплоя; чтобы сайт остался — привязать аккаунт в течение часа |
| **Cloudflare Pages** | Загрузить `dist` через «Upload assets» | Да, бесплатный |
| **GitHub Pages** | Запушить содержимое `dist` в ветку `gh-pages` | Да, бесплатный |
| **Timeweb / Beget / Reg.ru** | Залить `dist` по FTP в `public_html` | Платный хостинг, ~200 ₽/мес |

Для боевого запуска лучше обычный хостинг с российским доменом `.ru` —
это плюс к ранжированию в Яндексе по местным запросам.

Подойдёт любой статический хостинг: обычный shared-хостинг, Timeweb, Beget, GitHub Pages,
Netlify, Cloudflare Pages.

После публикации:

1. Добавьте сайт в Яндекс.Вебмастер и Google Search Console, отправьте `sitemap.xml`.
2. Заведите карточку в Яндекс.Бизнесе и 2ГИС по каждому городу — для локального
   поиска это даёт больше, чем сам сайт.
3. Проверьте микроразметку: <https://webmaster.yandex.ru/tools/microtest/>.

## Технические детали

- **Шрифты** — Oswald (заголовки) и Inter (текст), оба с кириллицей, подключены
  с Google Fonts. Если нужна независимость от внешних CDN — скачайте `.woff2`
  в `assets/fonts/` и замените `<link>` на `@font-face`.
- **Тёмная тема** — включается автоматически по системной настройке
  (`prefers-color-scheme`). Отдельного переключателя нет.
- **Доступность** — контрастность AA, фокус-кольца, `aria-label` у иконочных
  кнопок, скип-ссылка, минимальный тап-таргет 44–48 px.
- **Анимации** — уважают `prefers-reduced-motion`. Если JS не загрузится,
  контент всё равно виден (класс `.js` ставится инлайн-скриптом).
- **Микроразметка** — `LocalBusiness` на всех страницах, `FAQPage` на главной,
  `BreadcrumbList` на страницах городов.
- **Тема одна — светлая** (с тёмным первым экраном, блоком неисправностей
  и подвалом). Автопереключение на тёмную по системным настройкам отключено
  специально: иначе сайт выглядит по-разному у разных посетителей и его
  невозможно проконтролировать. Включить тёмную тему можно, добавив
  `data-theme="dark"` на `<html>` — стили для неё готовы в `style.css`.

### Осторожно с фотостоками

При подборе половина найденных кадров оказалась непригодной — на них были
**логотипы чужих компаний**: фирменная спецовка сервиса «ТЕХНОБЫТСЕРВИС»
на мастере, вывеска клуба «bfit» на стене зала, брендированные стойки «BOXPT».
Ставить такое на свой сайт нельзя. Если будете добавлять фото сами —
проверяйте кадр на посторонние логотипы, вывески и надписи.

Отобранные снимки этим не страдают. На `hero.jpg` видны марки оборудования
(Assault, Concept2) — это допустимо: мы это оборудование обслуживаем и прямо
перечисляем в блоке «Бренды».

### Заменить на свои

Стоковые фото — временное решение. Реальные снимки ваших работ (до/после,
разобранный узел, мастер на объекте) поднимают конверсию заметно сильнее
любого стока. Замените файлы под теми же именами — вёрстка не изменится.
Рекомендуемые размеры: `hero.jpg` — 1920×1080, остальные — от 900 px по ширине,
соотношение любое (обрезка по 4:3 делается через CSS).
